# 对象与数组

> 优先级：⭐

## 一、是什么

对象用键值描述一个实体；数组用有序集合保存多个值。API 响应、数据库记录、表单状态和 React 状态都大量使用它们。

## 二、为什么需要

对象与数组的核心难点不是语法，而是数据形状和更新方式：

- 取值可能得到 undefined
- 对象比较的是引用
- 某些数组方法会修改原数组
- React 状态不能随意直接修改

## 三、核心用法

### 对象读取

~~~js
const user = {
  id: 1,
  name: 'Xuhao',
  profile: {
    theme: 'dark',
  },
}

user.name
user['name']
user.profile?.theme ?? 'light'
~~~

### 不可变更新

~~~js
const nextUser = {
  ...user,
  profile: {
    ...user.profile,
    theme: 'light',
  },
}
~~~

### 常用数组操作

~~~js
const activeUsers = users.filter((user) => user.active)
const names = users.map((user) => user.name)
const firstAdmin = users.find((user) => user.role === 'admin')
const hasAdmin = users.some((user) => user.role === 'admin')
const allActive = users.every((user) => user.active)
~~~

## 四、核心原理

### 数组也是对象

数组拥有数字索引和 length，但项目中应该使用数组方法表达意图，而不是到处手动操作索引。

### 浅拷贝

~~~js
const next = { ...original }
~~~

只复制第一层，嵌套值可能仍然共享引用。

### 引用比较

~~~js
{} === {} // false
~~~

两个对象即使内容相同，只要不是同一个引用，严格相等就是 false。

## 五、常见场景

- 把 API 数据转换为页面数据。
- 新增、删除、编辑列表项。
- 维护表单状态。
- 按条件筛选集合。
- 把数据库记录转换成页面 DTO。

## 六、踩坑点

1. sort、reverse、splice 会修改原数组。
2. find 找不到时返回 undefined。
3. obj.key 和 obj[key] 的含义不同。
4. JSON 序列化深拷贝会丢失 Date、undefined 和函数。
5. 展开嵌套对象时必须逐层展开。

## 七、项目中的实际使用

根据 ID 更新：

~~~js
function updateTodo(todos, id, patch) {
  return todos.map((todo) =>
    todo.id === id
      ? { ...todo, ...patch }
      : todo
  )
}
~~~

删除：

~~~js
const nextTodos = todos.filter((todo) => todo.id !== id)
~~~

排序且保留原数组：

~~~js
const sortedTodos = [...todos].sort((a, b) => a.createdAt - b.createdAt)
~~~

## 八、一句话总结

对象描述实体，数组描述集合；更新项目数据时优先创建新引用，不直接修改旧值。

## 九、核心问答

### 1. find 和 filter 的区别是什么？

find 返回第一个匹配元素或 undefined；filter 返回所有匹配元素组成的新数组。

### 2. 为什么 React 中不推荐直接调用 state.items.push？

它直接修改旧数组，引用可能不变，框架和其他代码不容易正确判断状态变化。

### 3. sort 有什么隐患？

sort 会原地排序。需要保留原数组时，先使用 [...items].sort(compare)。

### 4. 可选链解决了什么问题？

当中间对象可能为空时，安全地停止读取并返回 undefined，避免直接抛出异常。

## 十、自测与答案

### 题目

1. 如何不修改原数组删除 ID 为 3 的元素？
2. 如何更新嵌套对象中的一个字段？
3. 为什么两个内容相同的对象严格相等仍可能为 false？
4. 哪些常用数组方法会修改原数组？

<summary>查看答案</summary>

1. items.filter((item) => item.id !== 3)。
2. 逐层展开，例如 { ...user, profile: { ...user.profile, theme: 'light' } }。
3. 对象比较的是引用，不是结构内容。
4. sort、reverse、splice 等。
