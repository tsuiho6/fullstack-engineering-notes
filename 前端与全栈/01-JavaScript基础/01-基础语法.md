# JavaScript 基础语法

> 优先级：⭐

## 一、是什么

JavaScript 是动态语言。变量在运行时保存值，值本身具有类型；TypeScript 后续会在这套运行时语义上增加静态类型检查。

主干可以记成：

~~~text
值 → 表达式 → 语句 → 函数 → 模块
~~~

## 二、为什么需要

React 和 Next.js 中很多问题来自 JavaScript 运行时，而不是类型注解：

- 对象、数组和函数是引用值
- undefined 和 null 可能在运行时出现
- 异步函数返回 Promise
- 闭包影响回调看到的变量
- 模块决定依赖边界

## 三、核心用法

### 1. 变量

~~~js
const name = 'Xuhao'
let count = 0
count += 1

const enabled = true
const empty = null
let missing
~~~

- 默认使用 const。
- 需要重新赋值时使用 let。
- 新代码不使用 var。

### 2. 条件与循环

~~~js
if (user) {
  showProfile(user)
} else {
  showLogin()
}

for (const item of items) {
  console.log(item)
}
~~~

处理集合时优先表达意图：

~~~js
const titles = posts
  .filter((post) => post.published)
  .map((post) => post.title)
~~~

输入：文章数组；输出：标题数组。

### 3. 相等与默认值

~~~js
value === other
value !== other

const name = input ?? '未命名'
const enabled = flag || false
~~~

优先使用严格相等。空值合并只在 null 或 undefined 时使用默认值；逻辑或会把 0、空字符串和 false 也当成假值。

### 4. 函数

~~~js
function add(a, b) {
  return a + b
}

const multiply = (a, b) => a * b
~~~

函数是值，可以保存、传递和返回。React 组件、事件处理器和数组回调都建立在此基础上。

### 5. 解构与展开

~~~js
const user = { id: 1, name: 'Xuhao' }
const { id, name } = user

const nextUser = { ...user, name: 'New name' }
const nextItems = [...items, newItem]
~~~

展开只做浅拷贝。

## 四、核心原理

### 值复制与引用复制

基本值复制的是值；对象、数组和函数复制的是引用：

~~~js
const a = { count: 1 }
const b = a
b.count = 2

console.log(a.count) // 2
~~~

直观理解：a 和 b 指向同一个对象。

### 真值

以下值在条件中为假：

~~~text
false、0、''、null、undefined、NaN
~~~

不要把“为空”和“值为 0”混为一谈。

## 五、常见场景

- 读取组件 Props 和 API 数据。
- 转换列表数据。
- 创建新的状态对象。
- 处理事件参数。
- 编写请求和工具函数。

## 六、踩坑点

1. const 不能重新绑定变量，但对象内部仍可修改。
2. 展开对象只复制第一层。
3. map 返回新数组，forEach 不返回转换结果。
4. filter 不修改原数组。
5. typeof null 的结果是 object。
6. || 和 ?? 的默认值语义不同。

## 七、项目中的实际使用

处理数据时采用“输入不变，输出新值”：

~~~js
function markRead(messages, messageId) {
  return messages.map((message) =>
    message.id === messageId
      ? { ...message, read: true }
      : message
  )
}
~~~

输入：消息数组和目标 ID；输出：新的消息数组。

## 八、一句话总结

JavaScript 的基本主线是：值通过表达式和函数流动，数组与对象通过引用连接，异步代码最终由 Promise 和事件循环驱动。

## 九、核心问答

### 1. 为什么 React 状态更新常常要创建新对象？

因为对象是引用类型。创建新引用更容易让框架判断数据发生变化，也能避免直接修改旧状态。

### 2. map 和 forEach 的区别是什么？

map 返回转换后的新数组；forEach 只遍历，不产生新的结果数组。

### 3. 0 || 10 和 0 ?? 10 分别是什么？

分别是 10 和 0。

### 4. 为什么优先使用 const？

它限制变量重新绑定，减少意外修改；对象内部是否可变需要另外控制。
