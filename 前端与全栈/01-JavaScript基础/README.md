# JavaScript 核心笔记

当前阶段只整理 JavaScript。TypeScript、React、Next.js 等内容后续分别使用对应资料整理，不混在本阶段。

## 一、学习目标

完成本组笔记后，能够：

- 解释 JavaScript 对象、数组、闭包、Promise 和事件循环。
- 写出正确的串行与并行异步代码。
- 判断什么时候应该创建新对象、什么时候不能直接修改原值。
- 把请求、数据转换和页面状态拆成清晰的模块。
- 解释常见异步代码的执行顺序，并避开高频陷阱。

## 三、推荐学习顺序

### 第一轮：建立最小闭环

~~~text
基础语法
→ 对象与数组
→ Promise
→ async/await
~~~

目标：能写出一个读取 API、处理数组并正确处理错误的脚本。

### 第二轮：补齐运行机制

~~~text
闭包
→ 模块
→ 异步与事件循环
~~~

目标：能解释回调为什么拿到旧值、模块如何组织依赖、Promise 为什么先于定时器回调执行。

### 第三轮：完成最小项目闭环

使用原生 JavaScript 完成一个小型任务列表或搜索页面：

- 从 API 获取数据
- 显示加载、成功、空数据和错误状态
- 过滤、编辑和删除对象数组
- 支持取消过期请求
- 把代码拆成多个模块

## 四、资料来源

- 原理和 Web API：[MDN JavaScript 指南](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide)
- 中文速查：[菜鸟教程 JavaScript](https://www.runoob.com/js/js-tutorial.html)

使用原则：

- MDN 用于确认原理、运行时行为和 Web API。
- 菜鸟教程用于快速理解和查询简单例子。
- 代码优先采用现代写法：const/let、模块、Promise、async/await、AbortController。

## 五、优先级说明

- ⭐ 必须掌握：变量、函数、对象、数组、模块、Promise、async/await、错误处理和事件循环。
- △ 理解即可：闭包的内存细节、宿主环境调度细节和不常用的语言边界。
- ○ 知道存在：低频语法、历史 API 和与当前 React/Next.js 主线无直接关系的浏览器细节。

## 六、笔记使用方式

1. 先读“核心主干”和“项目中的实际使用”。
2. 合上笔记，回答核心问答。
3. 不看答案完成自测。
4. 写一个最小可运行例子。
5. 把例子放进小项目，观察输入、输出和错误状态。

不要把笔记当成资料收藏夹。每篇都要服务于解释、写出、判断和避坑。
