# 总目录与学习顺序

## 一、是什么

算法是把输入转换成输出的有限、明确步骤；高效刷题要掌握的不是一组孤立模板，而是识别题目中的结构：有序性、单调性、重复状态、决策树和局部最优。

## 二、为什么需要

同一问题可以用暴力、分治、回溯、DP 或贪心解决，但它们利用的信息不同：

| 看到的结构 | 优先考虑 | 核心收益 |
|---|---|---|
| 有序数组/单调谓词 | 二分 | 每轮排除一半 |
| 需要全局有序或双指针 | 排序 | 把关系变成顺序 |
| 子问题彼此独立、可合并 | 分治 | 降低单次问题规模 |
| 需要枚举所有选择 | 回溯 | 系统遍历决策树 |
| 子问题重复且求最优/计数 | 动态规划 | 缓存状态，避免重复 |
| 存在可证明的局部选择 | 贪心 | 一次选择推进全局 |

## 三、核心用法

### 推荐学习顺序

1. **二分查找**：先固定区间表示和循环不变量，解决最常见边界错误。
2. **排序**：掌握 Go 标准库和复杂度边界，再理解快排/归并的分治思想。
3. **分治**：把递归、子问题和合并写成闭环。
4. **回溯**：用决策树枚举排列、组合、子集，并学会剪枝。
5. **动态规划**：把“重复的回溯状态”压缩成状态表。
6. **贪心**：学习何时可以只做局部选择，以及如何证明它不会错。
7. **综合训练**：练习区分“能写出来”和“能证明/判断适用”。

### 每道算法题的最小闭环

```text
目标 → 约束 → 最朴素解 → 可利用结构 → 状态/不变量 → 模板 → 证明 → 复杂度 → 边界测试
```

## 四、核心原理

### 1. 复杂度先于模板

若 `n` 达到 `10^5`，通常要把复杂度控制到 `O(n log n)` 或 `O(n)`；若 `n` 只有 20，指数级回溯可能正是题目预期。先看规模，再选算法。

### 2. 正确性来自不变量

- 二分：答案始终在搜索区间或谓词边界内。
- 排序：已处理区间保持某种有序性。
- 回溯：`path` 始终表示当前决策路径，返回时恢复现场。
- DP：每个状态的定义、转移和计算顺序一致。
- 贪心：当前选择不会破坏存在最优解的可能性，通常需要交换论证。

### 3. “会写”与“知道何时用”是两层能力

模板解决语法和边界；判断依赖题目约束和数学结构。尤其是贪心不能因为几个样例通过就认为正确，DP 也不能因为能写表格就认为状态定义正确。

## 五、常见场景

- `sort + 双指针`：两数/三数之和、区间合并、去重。
- `二分 + 单调判断`：最小可行容量、最大可行速度、答案空间搜索。
- `回溯 + 剪枝`：排列、组合、子集、棋盘放置。
- `DP + 状态压缩`：背包、打家劫舍、编辑距离、路径计数。
- `排序 + 贪心`：按结束时间、性价比或边界排序后选择。

## 六、踩坑点

- 二分的区间是闭区间还是半开区间，必须从头到尾一致。
- 排序后原始下标可能丢失，需要同时保存值和下标。
- 回溯结果必须复制当前路径，不能把同一个可变切片直接塞进答案。
- DP 的“状态”必须足以决定未来，不能只记录不完整信息。
- 贪心的局部选择必须有证明；“看起来合理”不算证明。
- Go 中递归深度、整数乘法溢出、原地排序和切片别名都要纳入检查。

## 七、项目中的实际使用

工程实现优先复用标准库：普通排序用 `sort.Ints` 或 `sort.Slice`；只有需要教学、特殊内存行为或题目要求时才手写排序。二分和 DP 则常常需要自定义边界和状态，必须配小样例与不变量测试。

## 八、一句话总结

**算法选择不是背答案，而是识别输入中的有序性、重复性、决策树和可证明的局部最优。**

## 九、核心问答

1. **二分和分治的关系是什么？**
   - 二分是每轮只保留一个子区间的分治特例；普通分治通常还需要合并多个子问题结果。
2. **回溯和 DFS 是同一个东西吗？**
   - DFS 是遍历方式；回溯是在 DFS 中做选择、递归、撤销，并通常维护路径和剪枝。
3. **DP 和回溯最关键的区别是什么？**
   - 回溯枚举具体选择路径；DP 合并具有相同未来影响的状态并复用结果。
4. **贪心和 DP 如何初步区分？**
   - 若当前最优选择可证明不会损害全局最优，贪心；若不同历史会导致不同未来，需要保留多种状态，通常 DP。
5. **排序为什么常常是其他算法的前置步骤？**
   - 排序把难以直接利用的关系变成单调顺序，从而支持双指针、贪心、区间合并或二分。

## 十、自测与答案

### 题目

1. `n=20` 和 `n=10^5` 时，算法选择的第一考虑分别是什么？
2. 一个题目要求“最小的可行值”，为什么容易想到二分答案？
3. 回溯中为什么要在递归返回前撤销选择？
4. 什么时候排序会破坏题目需要的信息？
5. 为什么贪心题必须额外关注证明？

<details>
<summary>答案</summary>

1. `n=20` 可以考虑指数级枚举并剪枝；`n=10^5` 通常必须寻找 `O(n)` 或 `O(n log n)` 结构。
2. “可行/不可行”若随答案单调变化，就能用二分定位第一个可行点。
3. 否则兄弟分支会继承上一个分支的状态，导致路径、计数或使用标记污染。
4. 需要原始下标、原始相邻关系或稳定顺序时；应保存索引或使用稳定排序。
5. 局部最优不自动推出全局最优，必须说明交换、边界或不变量为何保证正确。
