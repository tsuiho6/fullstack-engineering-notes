# 回溯

## 一、是什么

回溯是在决策树上进行深度优先搜索：做一个选择，递归探索，返回时撤销选择，再尝试下一个分支。它适合需要枚举所有合法方案或找到满足约束的方案的问题。

## 二、为什么需要

排列、组合、子集、棋盘放置等问题的候选数量本身可能是指数级。回溯不能凭空消除指数复杂度，但能用剪枝尽早排除不可能分支，把无意义的搜索砍掉。

## 三、核心用法

### ⭐ 通用模板

```go
func backtrack(state State) {
    if isAnswer(state) {
        record(copyOf(state))
        return
    }
    for _, choice := range choices(state) {
        if invalid(choice, state) {
            continue // 剪枝
        }
        apply(choice, &state)
        backtrack(state)
        undo(choice, &state) // 回退
    }
}
```

实际 Go 代码常用闭包和切片路径；`State` 不必真的定义成结构体，关键是保证“进入递归前做选择，返回前恢复现场”。

### ⭐ 子集/组合：用 start 避免重复

```go
func subsets(nums []int) [][]int {
    res := make([][]int, 0)
    path := make([]int, 0)
    var dfs func(int)
    dfs = func(start int) {
        res = append(res, append([]int(nil), path...))
        for i := start; i < len(nums); i++ {
            path = append(path, nums[i])
            dfs(i + 1)
            path = path[:len(path)-1]
        }
    }
    dfs(0)
    return res
}
```

输入输出形状是 `[]int → [][]int`；每个结果必须复制当前 `path`，否则所有结果会共享同一个可变底层数组。

### ⭐ 全排列：used 标记

```go
func permute(nums []int) [][]int {
    res := make([][]int, 0)
    path := make([]int, 0, len(nums))
    used := make([]bool, len(nums))

    var dfs func()
    dfs = func() {
        if len(path) == len(nums) {
            res = append(res, append([]int(nil), path...))
            return
        }
        for i, x := range nums {
            if used[i] {
                continue
            }
            used[i] = true
            path = append(path, x)
            dfs()
            path = path[:len(path)-1]
            used[i] = false
        }
    }
    dfs()
    return res
}
```

`start` 表示组合中只能向后选；`used` 表示排列中每个位置是否已经被当前路径占用。概念不同，不能随意互换。

### ⭐ 子集和 / 组合求和：目标驱动剪枝

若输入非负且已排序，可以在 `sum > target` 时停止当前分支：

```go
func combinationSum(nums []int, target int) [][]int {
    sort.Ints(nums)
    res := make([][]int, 0)
    path := make([]int, 0)
    var dfs func(int, int)
    dfs = func(start, remain int) {
        if remain == 0 {
            res = append(res, append([]int(nil), path...))
            return
        }
        for i := start; i < len(nums); i++ {
            if nums[i] > remain {
                break
            }
            path = append(path, nums[i])
            dfs(i, remain-nums[i]) // i：允许重复使用当前数
            path = path[:len(path)-1]
        }
    }
    dfs(0, target)
    return res
}
```

这个模板的“可重复使用”是题目特定规则；每个元素最多使用一次时递归到 `dfs(i+1, ...)`。排序和剪枝只有在剩余值单调时才正确。

### ⭐ N 皇后：把约束变成 O(1) 判断

```go
func solveNQueens(n int) [][]string {
    board := make([][]byte, n)
    for r := range board {
        board[r] = []byte(strings.Repeat(".", n))
    }
    cols := make([]bool, n)
    diag1 := make([]bool, 2*n-1) // row-col+n-1
    diag2 := make([]bool, 2*n-1) // row+col
    res := make([][]string, 0)

    var dfs func(int)
    dfs = func(row int) {
        if row == n {
            snapshot := make([]string, n)
            for i := range board {
                snapshot[i] = string(board[i])
            }
            res = append(res, snapshot)
            return
        }
        for col := 0; col < n; col++ {
            d1, d2 := row-col+n-1, row+col
            if cols[col] || diag1[d1] || diag2[d2] {
                continue
            }
            cols[col], diag1[d1], diag2[d2] = true, true, true
            board[row][col] = 'Q'
            dfs(row + 1)
            board[row][col] = '.'
            cols[col], diag1[d1], diag2[d2] = false, false, false
        }
    }
    dfs(0)
    return res
}
```

此代码需要 `import "strings"`。列、主对角线、副对角线的占用状态让合法性判断从扫描整行列降到 `O(1)`。

## 四、核心原理

### 1. 决策树

每层表示一次选择，节点表示当前路径状态，叶节点是完整方案或失败状态。总复杂度通常与决策树节点数相关，例如排列约 `O(n!)`，子集约 `O(2^n)`，还要乘上复制答案的成本。

### 2. 剪枝必须保持完备性

剪枝的含义是证明“这个分支及其后代不可能产生答案”。例如已排序且全为非负数时，当前数已经大于剩余目标，后面更大的数不可能修复它；若允许负数，这个剪枝就不成立。

### 3. 回退是恢复不变量

递归进入下一层前，`path`、`used`、棋盘和计数器代表当前选择；返回后必须恢复成进入前的状态。直观含义：每个兄弟分支都从同一个父状态出发。

## 五、常见场景

- 全排列、子集、组合、组合总和。
- N 皇后、数独、迷宫路径、棋盘放置。
- 需要返回所有方案，而不是只求一个计数/最优值。
- 约束满足问题，且 `n` 足够小或有强剪枝。

不适合：只求一个可行性/最优值且状态大量重复时，通常 DP 或图搜索更好；`n` 很大且没有剪枝时，指数搜索不可行。

## 六、踩坑点

1. **结果必须深拷贝路径**：`append(res, path)` 会让结果共享可变切片。
2. **回退要成对出现**：加入标记后，无论递归是否找到答案，都要撤销。
3. **排列和组合的去重规则不同**：排列关注元素位置使用，组合关注选择起点和顺序。
4. **重复元素要排序并跳过同层重复**：通常用 `if i>start && nums[i]==nums[i-1]`，不能跳过所有重复。
5. **剪枝依赖前提**：排序、非负、容量上界等条件不满足时不能套用。
6. **返回一个答案后是否继续**：题目要任意解可立即返回；要全部解必须继续搜索。
7. **棋盘状态的行列索引要一致**：对角线编码错一位会产生隐蔽错误。

## 七、项目中的实际使用

把回溯函数的状态写成注释契约：

```text
dfs(start, remain)：path 已选择的方案；只从 start 往后选；remain 是尚未满足的目标
```

工程中如果结果很多，要关注输出本身的内存下界；不能只优化搜索而忽略保存所有方案必然需要的空间。需要单个解时尽早返回，避免无意义枚举。

## 八、一句话总结

**回溯就是在决策树上“选择—探索—撤销”，剪枝必须有条件证明，结果必须复制。**

## 九、核心问答

1. **回溯和普通 DFS 的区别？**
   - 回溯额外维护选择状态、撤销现场和解空间剪枝，目标通常是枚举或满足约束。
2. **为什么组合用 `start`，排列用 `used`？**
   - 组合不允许回到前面，`start` 控制顺序；排列每层都可选任意未使用位置，需 `used`。
3. **什么时候可以用 `nums[i] > remain` 直接 break？**
   - 数组已排序，且后续数字不小于当前数、目标约束使更大的数不可能修复剩余值，例如全为非负。
4. **为什么回溯结果容易全部变成最后一个答案？**
   - 保存的是同一个 `path` 的引用/共享底层数组，没有在记录时复制。
5. **如何判断回溯是否已经不可行？**
   - 由当前状态的约束给出确定上界/下界/冲突；不能只凭经验剪掉“看起来不优”的分支。

## 十、自测与答案

### 题目

1. 子集模板为什么每次递归开始都可以记录 `path`？
2. 全排列中 `used[i]` 应在什么时候设为 true、什么时候恢复 false？
3. 组合求和允许重复使用当前数时，递归下标为什么传 `i` 而不是 `i+1`？
4. N 皇后如何 O(1) 判断同列和同对角线？
5. 如果输入有负数，为什么“剩余值小于当前值就 break”可能错误？

<details>
<summary>答案</summary>

1. 任意当前路径都是一个合法子集，递归继续扩展它即可得到更长子集。
2. 选择元素前设 true，递归返回、弹出 path 后恢复 false，保证兄弟分支干净。
3. 传 `i` 表示下一层仍可重复选择当前元素；传 `i+1` 表示每个位置只能使用一次。
4. `cols[col]`；主对角线用 `row-col+n-1`；副对角线用 `row+col`。
5. 后续负数可能把超出的剩余值拉回目标，数值单调性不成立，提前剪枝会漏解。

</details>
