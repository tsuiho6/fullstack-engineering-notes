# Hello 算法：算法高效笔记（Go + LeetCode）

这套笔记承接 `hello-algo-数据结构笔记`，整理 Hello 算法第 10–15 章。重点不是背算法名称，而是形成一条可迁移的判断链：

```text
题目约束 → 目标操作 → 单调性/重复子问题/局部最优性 → 算法模板 → 正确性边界 → 复杂度
```

## 优先级记号

- ⭐ 必须掌握：高频刷题、后续知识依赖、面试常问。
- △ 理解即可：知道思想、复杂度和适用边界。
- ○ 知道存在：遇到特定约束再查，不进入日常主干复习。

代码默认 Go 1.18+，使用 `[]int`、`map`、递归闭包和标准库 `sort`。涉及输入输出时会明确切片形状、下标区间、是否原地修改以及额外空间；Go 没有 Python/NumPy 意义上的 `dtype/device`，但整数溢出、`nil`、切片别名和递归深度仍需主动检查。

## 主干依赖

```text
复杂度与递归（已有前置）
        ↓
二分查找 ───────────→ 二分答案 / 分治搜索
        ↓
排序 ────────→ 双指针、贪心、区间处理、归并合并
        ↓
分治 ────────→ 递归树、树构建、归并思想
        ↓
回溯 ────────→ 决策树搜索、剪枝、排列组合
        ↓
动态规划 ────→ 重复子问题、状态压缩、背包
        ↓
贪心 ────────→ 局部最优 + 正确性证明
```

这不是严格的先后限制：排序和哈希表常常是其他算法的工具；回溯与 DP 都从“枚举状态”出发，但 DP 依靠状态复用，回溯保留具体选择路径。

## 使用方法

第一次学习：按 `00 → 01 → 02 → 03 → 04 → 05 → 06 → 07` 阅读，每篇只掌握最小模板。

刷题前：先看“适用信号”和“一句话总结”，合上文档写模板，再做题。

复习时：先回答核心问答；如果答不出，只回看对应的不变量、边界或证明，不从头重读。
