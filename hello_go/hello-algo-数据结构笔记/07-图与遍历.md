# 图与遍历

## 一、是什么

图由顶点（vertex）和边（edge）组成，用来表示任意对象之间的连接关系。图可以有向/无向、带权/无权、带环/无环；树是图的一种受限形态：连通、无环，且每个非根节点只有一个父方向。

## 二、为什么需要

当关系不再是“一对多的层级”，而是任意节点之间可能有多条路径、环或多个连通分量时，树不够用了。图把道路、依赖、社交关系、状态转移和网格都统一为“节点 + 邻接关系”。

## 三、核心用法

### ⭐ 邻接表：刷题默认

顶点编号为 `0..n-1` 时：

```go
g := make([][]int, n)

// 有向边 u -> v
g[u] = append(g[u], v)

// 无向边 u -- v：两边都要记录
g[u] = append(g[u], v)
g[v] = append(g[v], u)
```

输入输出形状是 `[][]int`；`g[u]` 是从 `u` 出发的所有邻居。无权图遍历时间 `O(V+E)`，空间 `O(V+E)`。

带权图把邻居从 `int` 换成包含 `To` 与 `Weight` 的结构体，例如 `[][]Edge`；有向边只写一侧，无向边写两侧。

### △ 邻接矩阵

`matrix[u][v]` 表示是否有边，或保存边权。查询某条边是 `O(1)`，但空间 `O(V²)`，适合顶点少、边很密、需要频繁判断任意两点是否直接相连的场景。

### ⭐ DFS：递归与显式栈

递归版：

```go
func dfs(g [][]int, start int) []int {
    seen := make([]bool, len(g))
    order := make([]int, 0)

    var visit func(int)
    visit = func(u int) {
        if seen[u] {
            return
        }
        seen[u] = true // 入栈/进入时标记
        order = append(order, u)
        for _, v := range g[u] {
            visit(v)
        }
    }
    visit(start)
    return order
}
```

如果顶点多、递归深度可能很大，用显式栈；仍然在入栈时标记，避免同一个节点重复入栈。

```go
func dfsIter(g [][]int, start int) []int {
    seen := make([]bool, len(g))
    st := []int{start}
    seen[start] = true
    order := make([]int, 0)
    for len(st) > 0 {
        u := st[len(st)-1]
        st = st[:len(st)-1]
        order = append(order, u)
        for i := len(g[u]) - 1; i >= 0; i-- {
            v := g[u][i]
            if !seen[v] {
                seen[v] = true
                st = append(st, v)
            }
        }
    }
    return order
}
```

### ⭐ BFS：队列 + 访问状态

```go
func bfs(g [][]int, start int) []int {
    seen := make([]bool, len(g))
    q := []int{start}
    seen[start] = true
    order := make([]int, 0)

    for head := 0; head < len(q); head++ {
        u := q[head]
        order = append(order, u)
        for _, v := range g[u] {
            if !seen[v] {
                seen[v] = true
                q = append(q, v)
            }
        }
    }
    return order
}
```

无权图最短距离：

```go
func distances(g [][]int, start int) []int {
    dist := make([]int, len(g))
    for i := range dist {
        dist[i] = -1
    }
    q := []int{start}
    dist[start] = 0
    for head := 0; head < len(q); head++ {
        u := q[head]
        for _, v := range g[u] {
            if dist[v] == -1 {
                dist[v] = dist[u] + 1
                q = append(q, v)
            }
        }
    }
    return dist
}
```

`dist[v]` 是从 `start` 到 `v` 的最少边数；不可达返回 `-1`。输出形状是长度为 `V` 的一维切片。

### ⭐ 连通分量

不要只从一个起点遍历；对所有未访问顶点启动一次 DFS/BFS：

```go
count := 0
seen := make([]bool, n)
for u := 0; u < n; u++ {
    if seen[u] {
        continue
    }
    count++
    // 从 u 开始遍历，并把遍历到的节点全部标记
}
```

### ⭐ 网格是隐式图

二维网格中每个格子是节点，相邻方向是边，不必显式建立 `[][]int`；用四个方向偏移计算邻居，先判断行列边界，再判断障碍或可走条件。障碍、岛屿、迷宫、最少步数等题，本质上是在隐式图上做 DFS/BFS。

## 四、核心原理

### 1. 邻接表和邻接矩阵的空间取舍

若边数为 `E`、顶点数为 `V`：邻接表空间约 `O(V+E)`，邻接矩阵空间 `O(V²)`。

直观含义：稀疏图不要为不存在的边分配空间；稠密图或频繁边查询才值得付出矩阵空间。

### 2. 访问标记为什么要尽早

在入队/入栈时标记，保证同一节点只进入容器一次；若出队时才标记，一个节点可能被多个前驱重复加入，虽有时最终结果仍对，但空间和时间会膨胀，带权或状态图中还可能导致错误处理。

### 3. BFS 的最短路条件

在无权图中，BFS 按边数从小到大扩展；第一次到达节点时，使用的路径就是最短边数路径。若边权不全相同，普通 BFS 不再保证最短，应考虑 0-1 BFS、Dijkstra 等后续内容。

### 4. 树为什么通常不需要 visited

从父节点向子节点走时，树没有环且每个子节点只有一个父方向；但如果题目允许从节点走向父节点，或把树当无向图处理，就必须记录访问状态。

## 五、常见场景

- **DFS**：连通性、岛屿数量、路径存在、状态探索、检测环的基础。
- **BFS**：无权最短路、按步数扩散、最少操作次数、层级遍历。
- **邻接表**：节点多、边相对少的绝大多数题。
- **邻接矩阵**：节点少且边密，或查询 `u→v` 是否直接相连特别频繁。
- **网格图**：岛屿、迷宫、腐烂扩散、棋盘移动。

不要把有向图默认当无向图加边；方向会改变可达性、入度、环和路径答案。

## 六、踩坑点

1. 无向边要加两次，有向边只按题意加一次。
2. BFS 访问标记要在入队时做，避免重复入队。
3. 图可能不连通，从一个起点只覆盖一个连通分量。
4. 节点编号范围要确认：`0..n-1` 才能直接用切片下标；任意 ID 用 map 映射。
5. 递归 DFS 可能栈过深：链状图/大网格考虑显式栈。
6. 网格边界先判断再访问，否则负下标或越界 panic。
7. 距离初值不能默认 0：用 `-1` 区分“未访问”和“起点距离 0”。
8. 重复边、反向边和自环要按题目处理，不要擅自去重。
9. 带权图不能直接套普通 BFS 最短路，先检查权重条件。

## 七、项目中的实际使用

工程里优先用邻接表，边结构明确方向和权重。若外部输入节点 ID 不连续，先建立 `ID → index` 映射；不要把外部字符串或大整数直接当切片下标。图遍历的返回值要明确是访问顺序、距离、父节点数组还是布尔结果。

## 八、一句话总结

**图先选表示，再选遍历：邻接表省空间，DFS 探索，BFS 按层找无权最短路。**

## 九、核心问答

1. **邻接表和邻接矩阵怎么选？**
   - 稀疏图优先邻接表；顶点少、边密或频繁判断任意两点直连时考虑矩阵。
2. **为什么 BFS 第一次到达节点就是无权最短距离？**
   - 队列按距离层序扩展，所有 `d` 步节点先于 `d+1` 步节点处理。
3. **DFS 和 BFS 都能判断可达，什么时候更偏向 BFS？**
   - 需要最少步数、按层扩散或最短无权路径时用 BFS。
4. **为什么只遍历一个起点可能漏答案？**
   - 图可能有多个连通分量；要统计全图或覆盖所有节点就要外层扫描未访问点。
5. **树和图的本质区别是什么？**
   - 树是有严格父子层级、连通且无环的受限图；图允许环、多个父节点和不连通。

## 十、自测与答案

### 题目

1. 无向边 `(u,v)` 为什么要写入 `g[u]` 和 `g[v]`？
2. BFS 访问标记放在出队时会产生什么问题？
3. 如何计算从一个起点到所有节点的无权最短边数？
4. 一个图有 10 个节点但只有 12 条边，邻接表相比矩阵的主要优势是什么？
5. 网格题中为什么不必显式创建每个格子的邻接表？

<details>
<summary>答案</summary>

1. 无向关系可双向通行；从任一端都必须能找到另一端。
2. 同一节点可能被多个前驱重复入队，增加开销；复杂状态下还可能重复更新答案。
3. `dist` 初始化为 `-1`，起点为 0，使用 BFS；首次发现邻居时写 `dist[v]=dist[u]+1`。
4. 图稀疏，邻接表只存实际的 `V+E` 规模；矩阵需要 `10×10` 的空间并包含大量不存在的边。
5. 邻居由固定方向和边界/障碍规则即时计算，显式建边既浪费空间又增加代码。
