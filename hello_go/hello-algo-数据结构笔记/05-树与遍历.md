# 树与二叉树遍历

## 一、是什么

树是由节点和父子边组成的层级结构；二叉树限制每个节点最多有左、右两个子节点。LeetCode 中最常见的形状是 `*TreeNode` 根指针，空子树用 `nil` 表示。

```go
type TreeNode struct {
    Val         int
    Left, Right *TreeNode
}
```

## 二、为什么需要

树把“一个整体拆成左右子问题”，天然支持递归和分治。很多题的关键不是记住某个遍历名称，而是回答：当前节点什么时候处理，子树返回什么信息，空子树的结果是什么。

## 三、核心用法

### ⭐ 术语与边界

- 根：没有父节点。
- 叶：没有子节点。
- 深度：从根到该节点经过的边数。
- 高度：从该节点到最远叶经过的边数；树高是根的高度。
- 子树：某节点及其全部后代。

有的题按节点数定义高度/层数，务必按题面校准；不要默认根高一定是 0 或 1。

### ⭐ 递归 DFS：处理时机决定遍历顺序

```go
func preorder(root *TreeNode, out *[]int) { // 根-左-右
    if root == nil {
        return
    }
    *out = append(*out, root.Val)
    preorder(root.Left, out)
    preorder(root.Right, out)
}

func inorder(root *TreeNode, out *[]int) { // 左-根-右
    if root == nil {
        return
    }
    inorder(root.Left, out)
    *out = append(*out, root.Val)
    inorder(root.Right, out)
}

func postorder(root *TreeNode, out *[]int) { // 左-右-根
    if root == nil {
        return
    }
    postorder(root.Left, out)
    postorder(root.Right, out)
    *out = append(*out, root.Val)
}
```

输入输出形状是 `*TreeNode → []int`；时间 `O(n)`；额外空间是递归栈 `O(h)`，`h` 为树高。

### ⭐ 迭代遍历：把递归栈显式化

前序遍历：

```go
func preorderIter(root *TreeNode) []int {
    if root == nil {
        return nil
    }
    ans := make([]int, 0)
    st := []*TreeNode{root}
    for len(st) > 0 {
        n := st[len(st)-1]
        st = st[:len(st)-1]
        ans = append(ans, n.Val)
        if n.Right != nil {
            st = append(st, n.Right) // 先入右，保证左先出
        }
        if n.Left != nil {
            st = append(st, n.Left)
        }
    }
    return ans
}
```

中序遍历要在左子树完成后处理根：

```go
func inorderIter(root *TreeNode) []int {
    ans := make([]int, 0)
    st := make([]*TreeNode, 0)
    cur := root
    for cur != nil || len(st) > 0 {
        for cur != nil {
            st = append(st, cur)
            cur = cur.Left
        }
        cur = st[len(st)-1]
        st = st[:len(st)-1]
        ans = append(ans, cur.Val)
        cur = cur.Right
    }
    return ans
}
```

### ⭐ 层序遍历：队列 + 当前层长度

```go
func levelOrder(root *TreeNode) [][]int {
    if root == nil {
        return nil
    }
    ans := make([][]int, 0)
    q := []*TreeNode{root}
    for head := 0; head < len(q); {
        size := len(q) - head // 本层节点数；先固定再入下一层
        level := make([]int, 0, size)
        for i := 0; i < size; i++ {
            n := q[head]
            q[head] = nil
            head++
            level = append(level, n.Val)
            if n.Left != nil {
                q = append(q, n.Left)
            }
            if n.Right != nil {
                q = append(q, n.Right)
            }
        }
        ans = append(ans, level)
    }
    return ans
}
```

输出形状是 `[][]int`：外层按层，内层按从左到右的节点值。若不需要分层，普通 BFS 不必保存 `size`。

### ⭐ 二叉搜索树（BST）

BST 的不变量：左子树所有键小于根，右子树所有键大于根；重复值策略必须由题目或实现规定。

```go
func searchBST(root *TreeNode, target int) *TreeNode {
    for root != nil {
        if root.Val == target {
            return root
        }
        if target < root.Val {
            root = root.Left
        } else {
            root = root.Right
        }
    }
    return nil
}
```

BST 查找、插入、删除的时间是 `O(h)`，不是永远 `O(log n)`；只有平衡时 `h=O(log n)`，退化成链时会到 `O(n)`。

### ⭐ BST 的中序遍历

若 BST 严格按左小右大构造，中序遍历得到升序序列。它常用于验证 BST、找第 K 小、按序处理键。验证不能只比较父子节点，要维护全局顺序或合法范围。

```go
func isValidBST(root *TreeNode) bool {
    var prev *int
    var walk func(*TreeNode) bool
    walk = func(n *TreeNode) bool {
        if n == nil {
            return true
        }
        if !walk(n.Left) {
            return false
        }
        if prev != nil && n.Val <= *prev {
            return false
        }
        v := n.Val
        prev = &v
        return walk(n.Right)
    }
    return walk(root)
}
```

### △ 数组表示完全二叉树

对完全二叉树使用 0 下标数组：

```text
left(i)  = 2*i + 1
right(i) = 2*i + 2
parent(i) = (i-1)/2  // i > 0，整数除法
```

它适合堆等近似满的树；普通二叉树有大量空位时用数组会浪费空间。空位标记不能和合法节点值混淆。

### △ AVL 树与自平衡

AVL 通过旋转保持左右子树高度差受限，使查找、插入、删除保持 `O(log n)`。原理要理解，手写完整旋转属于低频实现；刷题优先掌握普通树遍历、BST 性质和堆。

## 四、核心原理

### 1. 递归的最小闭环

写树递归前固定回答三问：

1. 空节点返回什么？
2. 当前节点需要从左/右子树得到什么？
3. 当前节点在前序、中序还是后序时机处理？

例如按节点数求树高：`height(nil)=0`，`height(root)=max(height(left), height(right))+1`。直观含义：最长路径等于较高子树的最长路径，再加当前根这一层。

### 2. DFS 与 BFS 的关系

递归 DFS 的调用栈就是隐式栈；迭代 DFS 显式使用切片栈；BFS 使用队列按距离层层扩散。它们都可能访问 `n` 个节点，但处理顺序和额外状态不同。

### 3. 树退化决定复杂度

平衡树高度约为 `log₂ n`，链状退化树高度为 `n-1`。直观含义：每次沿一条边把候选范围缩小一半才有对数复杂度；若每次只向后移动一步，就退化为线性。

## 五、常见场景

- **根-左-右**：复制树、序列化、先处理父节点。
- **左-根-右**：BST 有序处理、第 K 小。
- **左-右-根**：删除/释放、计算子树结果、后序依赖。
- **层序 BFS**：按层输出、最短层数、右视图、每层聚合。
- **BST**：精确查找、插入、顺序统计；前提是树真的满足 BST 不变量。
- **数组树表示**：堆、完全二叉树；普通稀疏树不推荐。

## 六、踩坑点

1. 递归先处理当前节点会改变遍历顺序；处理时机就是前/中/后序的定义。
2. 层序 `size` 必须在本层开始前固定，否则下一层节点会混入本层。
3. BST 验证不能只看父子，左子树深处的节点也必须满足祖先范围。
4. BST 不保证平衡；复杂度写 `O(log n)` 前要确认平衡条件。
5. 空树返回值要统一：遍历、计数、高度和布尔值各有不同基例。
6. 树高定义可能差一：按边数与按节点数相差 1。
7. 数组表示公式只适用于按层紧凑存储；普通稀疏树不能直接套父子下标。

## 七、项目中的实际使用

工程中节点结构要明确空值语义：

```go
// root == nil 表示空树；函数只读节点，不修改结构。
func contains(root *TreeNode, target int) bool {
    for root != nil {
        if root.Val == target {
            return true
        }
        if target < root.Val {
            root = root.Left
        } else {
            root = root.Right
        }
    }
    return false
}
```

需要序列化、持久化或跨进程传输时，不能直接传指针；应约定空节点标记和遍历格式。需要高频层序任务时，明确队列空间上限或及时清理已出队指针。

## 八、一句话总结

**树题先定递归返回值与处理时机；BST 靠顺序不变量，BFS 靠队列分层。**

## 九、核心问答

1. **前序、中序、后序到底差在哪里？**
   - 只差当前节点相对左右子树的处理时机：根-左-右、左-根-右、左-右-根。
2. **为什么 BST 查找不一定是 `O(log n)`？**
   - 普通 BST 可能退化为链，树高 `h` 变成 `O(n)`；只有平衡时才是 `O(log n)`。
3. **为什么层序遍历要记录当前层长度？**
   - 当前层处理时会把下一层加入队列；固定长度才能把输出按层分组。
4. **如何验证 BST 而不是只验证局部父子关系？**
   - 中序序列必须严格递增，或递归传递每个节点的合法上下界。
5. **什么时候用树节点，什么时候用数组表示？**
   - 普通稀疏树用节点指针；完全/近似完全树用数组更省空间且访问父子更快。

## 十、自测与答案

### 题目

1. 写出二叉树前序、后序的节点访问顺序，并说明当前节点的处理时机。
2. 层序遍历中 `size := len(q)-head` 的作用是什么？
3. 给出一个父子关系合法、但整体不是 BST 的例子。
4. 为什么堆适合数组表示，而普通二叉树不一定适合？
5. 如果递归求树高规定空树高度为 `-1`，叶节点高度是多少？

<details>
<summary>答案</summary>

1. 前序根-左-右，在递归展开子树前处理根；后序左-右-根，在两棵子树完成后处理根。
2. 固定进入本轮时已有的节点数；本轮新入队的节点属于下一层。
3. 根为 5，左子为 3，左子节点的右子为 7；7 大于父节点 3，但落在根 5 的左子树中，违反全局范围。
4. 堆是完全树，父子位置可由公式直接计算；普通树若稀疏会产生大量空位。
5. 叶节点高度为 0：左右子树高度 -1，取最大后加 1。
