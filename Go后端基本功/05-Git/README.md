# Git：章节总览

## 学习目标

知道 Git 如何记录快照；能用分支完成改动、检查差异、提交、同步、解决冲突并安全撤销。

## 章节顺序

1. [快照、暂存区与日常提交](./01-快照暂存区与日常提交.md)
2. [分支、合并与冲突](./02-分支合并与冲突.md)
3. [远端协作与安全撤销](./03-远端协作与安全撤销.md)

## 先掌握这些

- 工作区、暂存区、提交和分支引用的区别。
- 通过 status、diff、log 看清要提交的内容。
- 团队共享历史优先新增提交或 revert；reset 和强推要先确认影响。

## 资料

- [MIT Missing Semester：Version Control and Git](https://missing.csail.mit.edu/2026/version-control/)：先看这节课和练习，内容涉及快照模型、分支和冲突。
- [Pro Git 简体中文版](https://github.com/progit/progit2-zh)：完整参考书，按需查基础、分支、远端协作和撤销操作，不用一次读完。
