# Linux：章节总览

## 学习目标

能在 Linux 环境启动 Go 服务，查看进程、日志、端口、磁盘和内存，并从证据定位常见故障。

## 章节顺序

1. [Shell、文件与权限](./01-Shell文件与权限.md)
2. [进程、服务与日志](./02-进程服务与日志.md)
3. [资源、网络与故障排查](./03-资源网络与故障排查.md)

## 先掌握这些

- 文件路径、权限、环境变量、管道和退出码。
- 进程状态、信号、服务日志和监听端口。
- 磁盘满、内存紧张、端口冲突、域名解析失败的基本检查路径。

## 环境说明

在 WSL、虚拟机或 Linux 机器练习。systemd、包管理器和日志位置会随发行版与环境变化；先确认当前机器实际使用什么服务管理方式。
