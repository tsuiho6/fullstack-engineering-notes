# Go 语言简明教程：总览与学习路线

> 本教程把原先集中在一篇里的内容拆成专题，保留这个入口，方便按依赖顺序学习、回顾。主线是：**组织代码 → 理解值与数据 → 处理错误 → 建模 → 并发 → 验证交付**。

原始参考文章发表于 2019 年，示例背景是 Go 1.13。本套笔记保留仍然成立的语言原理，实践以现代 Go Modules、当前标准库和版本说明为准，不把旧文章当作当前语言规范。

## 版本与旧资料说明

- **模块是默认项目方式。** 新项目通过 go.mod 管理模块和最低 Go 版本；不再沿用早期教程里依赖 GOPATH、手动设置 GO111MODULE=on 的主线。
- **代码示例会标明最低语言版本。** 例如 slices 标准库从 Go 1.21 起提供；Go 1.22 的循环变量语义取决于模块 go 行；WaitGroup.Go 从 Go 1.25 起提供。
- **泛型有版本边界。** 类型参数在 Go 1.18 引入；Go 1.27 增加具体类型上的泛型方法，但接口仍不能声明泛型方法。基础项目仍优先用广泛兼容的泛型函数/泛型类型，并按项目目标版本选择语法。
- 截至 **2026-09**，官方发布记录显示最新稳定版本为 Go 1.27.1。学习时以目标项目的 go.mod 和官方发布说明为准，不必为了追新而把所有示例写成最新语法。

## 如何使用

1. 先按表格顺序阅读；遇到细节不必一次背完，先能解释并写出最小例子。
2. 每篇的自测题先独立回答，再展开答案；错题优先回到概念和输入输出边界。
3. 学完主干后，尝试完成第 10 篇中的小项目，再回头检查自己能否解释设计选择。
4. 具体库 API、版本新增能力和工具链行为，优先查 Go 官方文档并用本地目标版本验证。

## 依赖关系

~~~text
module / package / toolchain
        ↓
声明、类型、零值 ──→ 字符串、slice、map、指针
        ↓                         ↓
控制流、函数、error ───────→ struct、method、interface
                                     ├──→ type assertion / type switch
                                     ├──→ generics
                                     └──→ reflection（特殊场景）
        ↓
goroutine、channel、context
        ↓
test、race、build、最小项目
~~~

## 本教程的完成标准

- 能**解释**常见数据结构、接口动态值、错误包装和并发取消的关键行为。
- 能**写出**普通业务函数、清晰的错误路径、表驱动测试和可取消的 worker。
- 能**判断**何时选 slice/map/struct/interface/generics，而不是为了抽象而抽象。
- 能**避开** nil map 写入、map 顺序依赖、append 丢返回值、typed nil、goroutine 泄漏等高频错误。
